How this page stays current
  1. Ask Quartermaster to refresh the dashboard. One line in chat is enough.
  2. QM re-scans the council's files with its read-only scanner (build_dashboard.py), then updates the private Cursor dashboard.
  3. QM republishes this public copy with publish.py, which leaves out everything private and checks the page before it goes up.

Private parts (packages, deals and personal details) stay on the Cursor dashboard only. Format tags: game · web page · GitHub page · doc · product.
